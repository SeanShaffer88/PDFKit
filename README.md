# PDFKit

Planned PDF library with a C ABI, exploring parsing, text extraction, and generation.

**Status: fixture-only foundation.** The default branch currently contains a PDF test fixture, not an implemented PDF engine. There is no library source, public header, build guide, or release binary. The fixture does not establish PDF compatibility or supported features.

The first implementation milestone is a bounded PDF operation with a documented contract and validation against representative inputs. Record the existing fixture's provenance and redistribution terms before incorporating it into a distributable test package. No new license is assigned to that fixture by this README.
